# September 14, 2026: News, speech and email subscriptions

This release brings the recent local delivery work into the public source and
website. Production factors, model choices, alignment profiles and frozen
attribution records are unchanged. No always-on host or SMS service was added.

## Reader-facing changes

- News leads with the briefing and a prominent email subscription button. Four
  headlines are visible initially. Additional coverage, sources, calendar details
  and run records remain available in expandable sections.
- Related stories share a flagged-day explanation. Original source links and
  currency/date attribution remain available.
- Saved bilingual recordings use the optional Azure neural backend. Their scripts
  come from frozen briefing facts and checked notes. Playback never starts on its
  own. Earlier recording versions remain available.
- README and the English and Chinese Methodology page now describe input checks,
  limited official release-calendar coverage, speech and email delivery. A new
  shared SVG shows the saved-edition flow and uses the website's fonts.
- Brevo hosted form URLs accept one or two trailing padding characters. Embedded
  padding, unapproved hosts, query strings and fragments remain rejected in both
  the server validator and browser.

## Delivery boundaries

Morning and catch-up tasks check saved input dates before generation, reuse
existing packets and editions, and can request the registered live task within
a bounded retry budget. No new Task Scheduler trigger was introduced.

A separate probe checks the deployed edition, text, calendar and both MP3 hashes.
Email submission waits for that public check. A persistent daily/language claim
prevents automatic resubmission after an uncertain provider response. A fresh
installation needs its own service settings; no keys or addresses are bundled.

The target remains 09:00 America/New_York on weekdays, with same-day catch-up after
late login. The local computer must be awake, signed in and online. Publication
and mail queues can delay receipt. Old missed editions are not mailed as a backlog.

## Actual email acceptance

On September 14 the owner reported receiving and opening the confirmation email.
A read-only provider check then confirmed the owner's address in the dedicated
English subscription list, without an email block. The Chinese list had no
confirmed subscribers at that observation. No addresses are included here.

This establishes the English subscription-confirmation flow only. It does not
establish a completed daily briefing campaign, receipt of an audio link, Chinese
email delivery or unsubscribe. Those checks remain outstanding. No test campaign
was submitted as part of this documentation and website release.
