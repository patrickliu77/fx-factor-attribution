# Lasso 验证目标对照：实验前约定

2026-09-07，接续用户批准的下一项离线研究。在读取本轮结果前固定如下规则。
生产引擎、网站、数据、历史合同与调度均不变，不调用模型或下载数据。

## 只改变一个步骤

参照为现有 Lasso 调参方案：各时间验证折按惩罚后的 Lasso 系数计算验证误差。
候选方案在各折内先用 Lasso 选变量，再在该折训练样本的选中列上重估 OLS，用重估系数计算验证误差。
空选集使用零系数；验证目标仍以训练折的 y 均值中心化。

两方案在完整训练窗口上的最终步骤都保持为 Lasso 选变量、选中集合上的 OLS 重估。
两方案沿用训练折内标准化、相同顺时三折、初始 λ 网格、边界扩展规则和每 21 个观测重选频率。
具体扩展路径可能因评分不同而分开，它是验证目标变化的后果，会完整记录。
平分仍选网格中第一个最小值，不新增 one-standard-error 规则或非空约束。
不因候选表现不佳而换网格、删空集日、换样本或改菜单。

这里仅对齐 OLS 重估步骤。验证残差仍包含通过训练 y 均值处理的截距，
最终归因仍按生产规则把截距留在残差；本轮没有同时更改这个约定。

## 样本与范围

- 使用 `20260907-pilot-02/inputs/` 原始六货币快照，不重新构建输入。
- 使用原来的共同完整样本，CAD / NOK 也不撤销此前其他油价列带来的共同样本约束。
- 63 / 126 / 252 个观测窗口，分别从首个评估日前预留该长度训练历史。
- baseline 与 expanded 两套原有菜单，单模型不超过八列。
- 评估日期、provisional 规则不变：请求 2023-01-01 至 2025-12-31；实际排除重建前沿。
- 六货币 × 三窗口 × 两菜单，共 36 个配对，72 条拟合路径；保留全期与三个自然年。
- 126 参照检查 `pilot-02`，63 与 252 分别检查 `window63-01`、`window252-01`。

研究包内提供独立求解器和滚动驱动，不修改或替换生产模块的全局求解器。
训练缩放、量纲还原和训练 R² 复用现有 `_fit_once`；增加的代码需要合成测试和真实参照复现。
36 条参照的逐日 β、λ、选集、贡献、残差等必须与旧实验完全一致，否则停止接受结果，先查实现差异。

## 指标与证据

沿用 MAE、RMSE、尾部残差、尺度调整后 β 变动、贡献 L1、选集切换率与选中频率。
新增汇总 λ 改变率和空选集率差，以候选减参照表示，空集率差的单位为百分点。
错误越小与空集越少分别讨论，不把空集减少直接当作成功。
保存各次重选的完整 λ 网格、折误差曲线、最终 λ、边界情况、训练截止日及 full / exog 标识。

成对移动区块 bootstrap 沿用 5 / 21 / 63 个保留观测、1000 次、固定种子。
区间条件于已拟合路径，不在每次重采样中重训，也不校正多重比较。
历史已经使用过，不能称为新测试集；不同窗口不能当作独立样本。
目标是检验验证目标是否影响估计与选择，不作因果或预测收益声明。
