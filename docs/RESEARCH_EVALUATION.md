# 离线归因评估协议 v1

2026-09-07。用户已批准继续“离线评估工具 + 真实运行记录核对”的研究计划。
此文件在首轮结果产生前固定问题、样本和读法。生产菜单、偏移、模型、任务和网站不变。

## 三个问题

1. 同菜单估计器：baseline 的 OLS、Ridge、post-Lasso，相同 X、y 与训练起点。
2. 菜单效果：post-Lasso baseline 对 post-Lasso expanded，只改变候选列。
3. 油价代理：CAD WTI 对 Brent；NOK Brent 对 WTI。分别固定 OLS、Ridge、post-Lasso 和 baseline 其余列。没有 WCS 数据时不伪造代理，也不加入生产菜单。

每个估计器最多八列。CAD / NOK 的共同样本检查可以涉及九个候选列的并集，
但没有任何一次回归同时使用九列。油价替换只采用已经接入的价格序列和既有 pair 偏移。
不重新挑选偏移，不同时把 Brent、WTI 加进某一模型。

## 首轮范围与证据等级

- 先跑六货币、126 观测窗口；工具支持原有 63 / 126 / 252 窗口。
- 固定评估期 2023-01-01 至 2025-12-31；同时按自然年报告。
- 原始市场数据只读本地 parquet 缓存，HY OAS 只读用户归档 CSV。
  归档截至 2026-02-06，当前未保存可独立重建之后 OAS 的离线尾段。
  所以首轮不把 2026 年混入，也不在线补数。超过归档范围直接拒绝运行，不静默截断。
- 历史已经被项目开发使用，明确标为回顾性、探索性评估，不能称为未接触过的最终测试集。
- 输出是截至前一观测拟合 β、当天实际 X 已知条件下的重构误差；没有交易收益、预测准确率或因果效果声明。

## 控制变量

逐 pair 构造全部实验所需列的共同完整样本。保存每一步损失与日期，baseline 也采用
同一候选并集的日历，避免样本差异冒充估计器改善。不同货币不强制共有日期。
输入在截断日以前构建；训练预处理由现有 rolling 引擎和各验证训练折独立估计。
λ 每 21 个观测重选，每个实验独立初始化状态；所有实验有同样的训练起点。
评估排除 provisional；该标记是截断后重建的保守前沿状态，不是历史原始 vintage。
缺失筛选仍会选择样本，这一局限需要随报告披露。

## 输出指标

- MAE、RMSE、绝对残差 95 分位，均为 log-return bp；零贡献参照单列。
- 训练 R² 仅作诊断，不与评估重构指标混为一谈。
- 相邻有效观测的原量纲 β 变动逐因子保存；另用前一期训练标准差缩放，报告 bp 尺度的系数变动，不以原始 β 跨因子排名。
- post-Lasso 空集率、选集转换率、选中频率。
- 成对 RMSE、MAE 差；对照日期完全相同，候选减参照，负值代表残差更小。
- 同菜单与菜单实验用逐因子贡献 L1；油价实验另将 WTI / BRENT 映射为单一 OIL 通道再比较，避免不同名称被误算为两倍差异。
- 固定 5 / 21 / 63 个保留观测的移动区块 bootstrap，1000 次、种子固定。
  同一抽样索引同时作用于两臂误差，给 RMSE 差的点对点 95% 区间。
  序列不首尾环绕；样本少于两个区块不报区间。
  该区间条件于已拟合路径，没有重跑全部模型与选择过程；不是多重检验校正或因果置信区间。
  区块长度敏感性与按年结果共同阅读，不按某一个区间决定生产切换。

每族成组回归配汇总图；罚回归及选择后 t 值不伪装成普通 OLS 推断。
报告保留数表、逐日路径和输入快照，记录源码、输入与设置哈希。
相同快照可以重跑到新目录。已有输出目录拒绝覆盖；生产目录不作评估输出目的地。
首次运行与重放均不调用在线取数、新闻模型或发布脚本。

方法背景：[scikit-learn 时间验证与折内预处理](https://scikit-learn.org/stable/modules/cross_validation.html)、
[arch 移动区块 bootstrap 定义](https://bashtage.github.io/arch/bootstrap/generated/arch.bootstrap.MovingBlockBootstrap.html)。
实现沿用本项目自定义顺时切分；区块抽样直接用 NumPy，无新增 arch 依赖。

## 运行验收并行记录

只读保存的状态、晨报档案和日志，单独存证，不改变现有调度。
主动暂停与技术故障分别记录，公开协议省略个人日程。
本轮不伪造一周连续观察，不用一次日志绿色证明整链路已自然验收。
新闻人工标签仍需用户或声明身份的复核者填写，本轮不会生成假人工评分。

## 实施与验收

新增独立 research 包：只读输入与快照、实验执行、统计比较、离线 HTML/SVG 报告、命令行入口。
测试覆盖同样本、无当日训练、独立状态、单位、油价名称、快照篡改、输出保护、无网络及计算恒等式。
遵守现有 tests/conftest.py 的全 outputs 隔离。全部测试通过后交付本地研究报告与结论。
