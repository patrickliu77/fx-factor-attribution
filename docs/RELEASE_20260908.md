# September 8, 2026 release

This release brings the public source up to date with the tested dashboard and local
operating tools. Model revision remains `2026-09-04.fold-local-cv-pca`; contract schema
remains `1.1.1`. The closeout does not change model parameters or frozen historical rows.

## Included

- Offline research compares estimators, factor menus, oil proxies, training windows
  and Lasso validation objectives, with saved inputs and paired-sample diagnostics.
- Input archives preserve the actual tables observed by live runs. Content hashes
  identify objects; verification and revision comparisons work offline.
- Morning acceptance connects preparation, edition and push receipts. A separate
  login catch-up job publishes a clearly labelled late edition when possible.
- A windowless supervisor records attempts, native exits, timeouts and last success.
  Website status separates failed attempts from readable older data. Static status
  remains a build-time observation.
- Gemini requests retain safe error categories, HTTP status when available, timing
  and bounded retries. Frozen editions are not regenerated on retry.
- News groups conservative event matches and collapses repeated reporting. Mini
  charts colour only the daily comparison segment. PCA is visible on Attribution.

## Evidence and limits

The September 8 reliability suite passed 722 tests with no failures or skips.
Browser checks covered 27 attribution selections and English/Chinese desktop and
mobile layouts on localhost and the public site. A successful recovery advanced
attribution to September 8; all 225,495 previously final rows retained identical
fingerprints. One missing USD/JPY news note passed the existing six checks.
These checks do not establish semantic accuracy for all future news.

A native Python crash returned `0xc000001d` earlier that evening. Archived-input
replay and a subsequent live run completed, so the crash was not reproduced.
Its root cause remains unresolved. New diagnostics improve visibility; they do not
prove that the underlying fault has been eliminated.

Formal morning acceptance remains 0/5 consecutive weekdays. The afternoon catch-up
is a separate numbers-only edition; its failed generation records remain frozen.
Manual tests and late editions do not count as on-time delivery. No audio or independent
multi-agent orchestration is included. An economic calendar and stronger semantic
evaluation remain future work.

## Reproduction and deployment

Use `requirements.txt`, set `PYTHONPATH=src`, and run `python -m pytest` for the
isolated offline suite. The [operations guide](../ops/README.md) covers acquisition,
research and supervision. Reproducing historical experiments requires their saved
input snapshots; source alone cannot recover historical data vintages or generated text.

Public `main` stores code and documentation; `gh-pages` stores the generated site.
Notes, raw data, caches, private reports, task XML and crash dumps are not published.
The local host must be on and signed in for new runs. Catch-up cannot guarantee
immediate availability when the preceding attribution run is missing.
